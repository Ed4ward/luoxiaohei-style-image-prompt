# 罗小黑风格图片提示词

先读 `references/luoxiaohei-visual-style.md`，选择适合场景的动画质感和构图。默认采用电影感二维动画画面，保留轻松的生活动作和非常克制的奇幻细节。用户指定早期番剧的简笔感时，采用更平面的色块、更少的背景笔触和更大的留白。

## 写提示词

先固定主体、地点、数量、物件特征和用户指定的画幅或文字。用一帧能看懂的动作串起人物、环境和道具。真实地点保留两三项可辨识的地标特征。用户给了参考图时，按指定范围保留主体外形、配色和构图关系，再改变画法。自由创作时采用原创角色，以场景需要决定是否出现动物或精怪。

默认采用下列顺序，写 6–9 行。仅保留对本图有作用的字段。无角色要求时，场景可以靠风、影子、雨点或移动中的物件产生动作。

```text
画风：参考《罗小黑战记》的手绘二维动画，简练的角色轮廓、平涂色块、轻薄的背景笔触。
场景与主体：[地点和主角，保留两三项辨识特征]
画面时刻：[一个动作，接一个可见反应]
奇幻细节：[零或一个能参与动作的小异常]
构图：[景别、视点、清晰的主体位置或留白]
色光：[两三种主要颜色与一个光源或天气线索]
画幅：[按用户要求或主体比例选取]
画中藏字：[确切字样、哪几处画面里的形状画成关键笔画、可见程度；找不到自然落点时省略]
```

## 画中藏字

先从动作或道具附近选一处现有形状来藏字。像画背景一样手绘字的关键笔画，让水纹、倒影断线、叶脉或石纹直接成为笔画。字的粗细、曲直、高低和疏密随画里的形状变化。保留读序和能辨字的关键结构，其余笔画可以借用相邻纹理或自然断开。普通观看时像场景细节，放大才读得出来。正式招牌或用户指定的排版按场景需要处理。

从这一帧的动作、意象和情绪里取字。安静或浪漫的画面可以用有余韵的四五字短句，例如以「秋水有信」呼应落叶和雨水。轻松热闹的场景可以用道具上的短玩笑。字义留一点给观众联想。

- 用户只说「加一些字」或「加彩蛋」时，优先理解为画内藏字。用户明确指定标题、对白、字幕、字样或位置时按其要求处理。用户明确要求无字时，省略文字字段。
- 编辑已有图时优先利用原图里的一件物体或表面。用户点名保留的招牌、地标名称及产品文字照原样处理，把彩蛋放到别处。

## 输出

- 用户要提示词、只给了主题或写明「不用出图」时，用用户指定的语言只返回一个最终提示词代码块。按要求提供多张时，为每张整理独立的提示词。
- 用户明确要求画图或出图时，先写好提示词，再调用可用的图像生成工具。先看整张图，检查那些形状能否自然地读作水纹、叶脉等画面细节，再放大确认仍能按顺序辨字。字样像独立写上去的字带、抢焦点、有错字或漏字时，优先对那一小处重做。出图回复保留找彩蛋的乐趣，按用户要求再透露藏的位置。用户同时要求提示词时，一并提供。图像生成工具不可用时，交付提示词并说明出图状态。
