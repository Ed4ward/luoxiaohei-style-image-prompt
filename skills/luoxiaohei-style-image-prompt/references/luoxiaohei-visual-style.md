# 罗小黑式二维动画画面

## 画法与分镜

| 维度 | 提示词写法 |
| --- | --- |
| 角色 | 用清楚的剪影、简练的五官和一两块阴影。把表情写进眼神、重心、耳朵或手势。描述原创角色时，选一两项轮廓和服装特征即可。 |
| 背景 | 让角色线条更清楚，背景用较柔的边缘、薄薄的手绘笔触和稀疏细节。近处和远景用颜色、明度与遮挡拉开距离。 |
| 用色 | 给场景选两三种主色。比如雨后用灰青和冷绿，局部用路灯暖黄。高饱和色集中在动作或观察点附近。 |
| 景别 | 交代地方时用远景或全景，角色之间的动作和反应多用平视中景，道具的变化用近景。选一个视点，让主体周围留出可读的轮廓。 |
| 时间点 | 选动作刚开始、即将接触或反应刚发生的一瞬。比如手还没碰到纸伞，伞影已经往旁边挪开。单帧集中在一个事件。 |
| 奇幻 | 从生活里取材料。风、影子、树叶、水珠和路灯都可以承载奇幻感。优先让细节回应角色或环境动作，轻快的日常场景也可以完全没有奇幻元素。 |

用具体可画的形状、颜色和动作代替「高清」「杰作」「唯美」等宽泛词。画面默认采用完整动画单帧。若模型容易误解媒介，可在画风一行加上「二维平涂，柔和手绘背景」，并按需要排除摄影质感或 3D 渲染。

## 画中藏字

木头的采访里提到番剧短暂闪过的 MTJJ 署名和催更吐槽，也举了电影里拿「没人看对联」自嘲的对联。番剧的场景还把署名融进砖块与树影。借用这些做法时，为新画面写自己的字，让文字与道具、环境或正在发生的事有关。

番剧的地下化石镜头把「不要催更才是正题」化进左下暗色地层。篆书竖向错落，字有高矮宽窄，笔画和泥土里的细线接在一起。借鉴这一帧时，先看载体已有的边缘、裂纹或色块，再给每个字找落点。只压低亮度的等高等距字样仍容易被看成排版。[原动画截帧](https://imgpai.thepaper.cn/pphimage/20261115/f99aa046-6321-49ee-926f-e6e41f625fe0.jpg)

| 场景 | 载体 | 原创例子 |
| --- | --- | --- |
| 地标或自然场景 | 涟漪、残碎倒影、叶脉、岩缝。用这些形状直接画出能辨字的笔画。 | 「秋水有信」从落叶激起的水纹和瓦檐的碎倒影里显出一点轮廓。 |
| 街巷和室内 | 侧挂小木牌、旧票根、标签、菜单角落。让字体像店主或使用者写的。 | 雨巷里修伞摊的小侧牌写「只补晴天」。 |
| 人物与物件 | 袖标、伞骨旁的记号、杯底印章、杯垫背角。文字沿曲面或织纹走。 | 马克杯边的旧软木杯垫有个「云」字小印。 |

在提示词的一行里给出确切字样和载体，再指定画面上两三种已有形状如何组成笔画。比如让涟漪的分叉成为「水」的撇捺，让碎倒影成为「有」的短横，笔画保留水面原有的颜色和边缘。把字集中在一小处，沿相邻纹理自然排出读序。通常用 2–6 个汉字或一个短缩写，单字大小跟着载体走。把断续、磨损留在次要笔画，让关键结构放大后仍能辨认。较长的句子留给招牌或道具特写。多张图可用同一个原创印记呼应前后画面。

## 场景取舍

- 真实地点优先保留屋脊、桥体、立面、河道或街巷走向等能辨认的结构。把奇幻细节放在一处日常互动里，让地标承担画面辨识度。
- 角色场景突出人物之间的行为关系。用递伞、让座、躲雨或交换视线替代只有站姿的人物排布。用户指定单角色时，让动作与环境或道具发生关系。
- 产品与物件保留整体形状、颜色、图案和用户要求的标识。通过桌面、水汽、窗光或影子表现动画感。仅在用户要求拟人化时增加脸或肢体。

## 示例

### 北京故宫雨后

```text
画风：参考《罗小黑战记》的手绘二维动画，角色轮廓简练，色块平涂，建筑背景带柔和手绘笔触。
场景与主体：雨后故宫太和殿，金色重檐、朱红柱列和汉白玉台基，一位撑深青纸伞的少年站在石砖广场上。
画面时刻：少年放低伞沿，低头看一片银杏叶刚落入脚边的水洼。
奇幻细节：水里的银杏叶倒影轻轻转头，像一尾小鱼。
构图：平视全景，人物小而清晰，宫殿屋脊完整，水洼留在画面下方。
色光：灰青天空、朱红柱列、雨后薄薄的暖金天光。
画幅：横向 16:9。
画中藏字：「秋水有信」散在水洼边一小段自然弯曲的水纹里。「秋」的禾与火由一束细长倒影和几道碎涟漪画成。「水」用三道分叉水纹画开。「有」与「信」借瓦檐倒影的断线成形。笔画跟着水面起伏，颜色和周围倒影接上，细看可按顺序读出。
```

### 湖蓝色马克杯

```text
画风：参考《罗小黑战记》的手绘二维动画，简练线条、清楚的平涂色块和轻薄的窗边背景笔触。
场景与主体：老木窗台上的湖蓝色马克杯，保留半月形把手、杯口白边和杯身的一颗白星。
画面时刻：杯口蒸汽刚碰到吹进窗的微风，向右舒展开。
奇幻细节：蒸汽末端短暂形成一只燕子的轮廓。
构图：平视近景，杯身和把手清晰，右侧留空给蒸汽。
色光：湖蓝、木棕与淡米白，左侧晨光照亮杯口。
画幅：竖向 4:5。
画中藏字：旧软木杯垫露出的一角印一个「云」字，字迹是淡棕色，沿杯垫倾斜。
```
